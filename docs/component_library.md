# Component Library Specification
## Astygma Hope Clinic - UI Elements Catalog

### 1. Core Component Hierarchy
1. **Navigation Components**:
   - `Navbar`: Sticky glassmorphism bar with Clinic Logo, Navigation Links, Language Switcher (EN/MR/HI), Theme Selector, and Emergency Call/WhatsApp button.
   - `Footer`: Detailed multi-column footer with Branch address, Working hours, Doctor accreditation, Emergency contacts, and Admin login entry point.
2. **Patient Facing Components**:
   - `HeroBanner`: Animated headline with background video/image glass overlay and CTA buttons.
   - `DoctorCard`: Profile card for Founder Dr. Umesh D. Kalekar (31+ Yrs Exp) & Specialist slots.
   - `SonographySection`: Dynamic showcase with media gallery and dedicated `/assets/sonography` integration.
   - `TreatmentCardGrid`: Interactive cards for Female/Male Infertility, Pregnancy Care, Ultrasound, Lab Tests, Yoga Therapy, Sangeetopchar, Suprajaa Nirmiti, etc.
   - `AppointmentModal`: Modal request form with date picker, service selector, patient details, and auto WhatsApp redirect trigger.
   - `SoundVaultPlayer`: Password-protected audio player with interactive visualizer wave and category filters.
   - `InstagramCMSFeed`: Story bubbles, carousel viewer, blog cards, and health tip banners.
3. **Admin & Clinical Dashboards**:
   - `AppointmentTriageTable`: Linear-style data grid with status filters (Pending, Approved, Completed, Cancelled).
   - `CMSPostEditor`: Form for image/video/story upload and publishing.
   - `ThemeConfigurator`: Live palette switcher and custom typography editor.
