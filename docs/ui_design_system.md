# UI Design System & Aesthetic Principles
## Astygma Hope Clinic - Design Tokens & Visual Specs

### 1. Design Philosophy
- **Apple-Level Elegance**: Fluid geometry, subtle glassmorphism (`backdrop-filter: blur(16px)`), precision border glows, and harmonious typography hierarchy.
- **Tesla-Level Simplicity**: Clean visual paths, zero clutter, single-click appointment request workflows.
- **Stripe-Level Micro-Animations**: Smooth tab transitions, hover elevations, and interactive sound visualizers.
- **Linear-Level Dashboard Precision**: Compact data tables, quick action menus, and status badges.

---

### 2. Color Palette & Theme Tokens

#### Light Mode (Warm Minimal Luxury)
- **Background Primary**: `#FDFBF7` (Warm Cream / Ivory)
- **Card / Surface**: `rgba(255, 255, 255, 0.85)`
- **Accent Primary**: `#0F4C3A` (Deep Emerald Green)
- **Accent Secondary**: `#D4AF37` (Champagne Gold)
- **Text Main**: `#1C2520` (Dark Slate Green)
- **Text Muted**: `#5A6B63`

#### Dark Mode (Obsidian Luxury)
- **Background Primary**: `#09110D` (Deep Emerald Obsidian)
- **Card / Surface**: `rgba(18, 30, 24, 0.75)`
- **Accent Primary**: `#2DD4BF` (Bright Teal Glow)
- **Accent Secondary**: `#F59E0B` (Warm Gold)
- **Text Main**: `#F1F5F9`
- **Text Muted**: `#94A3B8`

#### Festival Themes
- **Diwali Theme**: Royal Ruby (`#881337`), Radiant Gold (`#F59E0B`), Deep Amber (`#78350F`).
- **Navratri Theme**: Mystic Violet (`#581C87`), Emerald Glow (`#047857`), Festival Copper (`#B45309`).

### 3. Typography Hierarchy
- **Primary Font**: `Inter`, `system-ui`, `-apple-system`, `sans-serif`
- **Serif Display Accent**: `Playfair Display`, `Georgia`, `serif`
- **Scale**:
  - `Display 1`: 3.5rem (56px) | Font-Weight: 700 | Line-Height: 1.1
  - `Heading 1`: 2.5rem (40px) | Font-Weight: 600
  - `Heading 2`: 1.75rem (28px) | Font-Weight: 600
  - `Body Large`: 1.125rem (18px) | Font-Weight: 400
  - `Body Regular`: 1rem (16px) | Font-Weight: 400
  - `Caption`: 0.875rem (14px) | Font-Weight: 500
